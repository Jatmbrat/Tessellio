# Tessellio
Tessellated binary puzzle game

This project was started to see if it was possible to make a Takuzu/binary puzzle work on a an irregular and semi-regular tiled grids.  As evidenced by its existence, it is possible, so long as the tiling patterns meet certain criteria.  The usual "no 3-in-a-row" and "no similar lines" rules have been replaced with a disjoint set rule.

## Controls

The game is mainly played with a mouse, but there are a selection of available shortcut keys:

<p>Z - UNDO<br>
Y - REDO<br>
R - RESET LEVEL<br>
Q - RULES/CONTROLS PAGE<br>
O - OPTIONS<br>
G - EXIT<br>
C - CLEAR NOTES<br>
K - CHECK PUZZLE<br>
ESC - BACK OUT<br>
TAB - TOGGLE DRAW MODE</p>
